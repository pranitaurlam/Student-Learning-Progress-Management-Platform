# 🎓 MindForge Academy – Student LMS Portal

A premium, modern learning management system (LMS) portal designed exclusively for students. Features include a dashboard with progress tracking, mentor chat, and subject-specific study materials.

## 🚀 Features
- **Student Dashboard**: Track streaks, view courses, and monitor progress.
- **Messages**: Real-time interaction with mentors and professors.
- **AI Doubt Chat**: Instant AI assistance for academic queries.
- **Doctor Chat**: Health and counseling support.
- **Study Materials**: Access to research papers, notes, and cheatsheets.

## 🏗️ Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`
