Python Cheat Sheet

Basics

Variables: x = 5, name = "Alice"

Print: print("Hello World")

Comments: # This is a comment

Data Types

str: "Hello"
int: 10
float: 20.5
bool: True, False
list: [1, 2, 3]
dict: {"key": "value"}

Control Flow

if x > 10:
    print("Large")
elif x == 10:
    print("Equal")
else:
    print("Small")

# Loops
for i in range(5):
    print(i)

while x > 0:
    x -= 1

Functions

def greet(name):
    return f"Hello, {name}!"

print(greet("Bob"))
